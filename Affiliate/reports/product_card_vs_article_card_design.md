# 商品カード vs 記事カード — 使い分け

| | 記事カード | 商品カード |
|---|---|---|
| 置く場所 | 記事一覧・カテゴリ・関連記事 | **記事本文の中だけ** |
| 画像 | オリジナルアイキャッチ（自作） | 各ASPの正規商品画像 |
| 主役か | 一覧の主役 | 記事の“補助”（主役でない） |
| リンク先 | 記事ページ | Amazon/楽天/Yahoo/A8 |
| PR表記 | 収益化記事に控えめラベル | カード内に「※広告・PRを含みます」 |
| 個数 | 制限なし（一覧） | 1記事2〜5個まで |
| 禁止 | 商品画像の使用 | /app CTA直前直後・見出し直後広告と隣接 |

## 原則
- **一覧＝記事カード（売らない）／本文＝商品カード（自然に）**。
- 両者を混同しない。一覧に商品カードを出さない。
- 設計詳細：`Content/structure/article_card_design.md` / `product_card_component_design.md` / `monetized_article_card_design.md`。
