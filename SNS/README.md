# SNS 運用フォルダ ― 親みまもり研究所

X アカウント **@oyamimamori_jp（親みまもり研究所）** の投稿素材を管理するフォルダです。
※ 今回は **X のみ**。Instagram は別日に作成します。

- サイト: https://www.oyamimamori.jp/
- アプリLP: https://www.oyamimamori.jp/app/

## フォルダ構成

```
SNS/
├── README.md                       ← このファイル（運用ルール）
├── strategy/                       ← 運用方針メモ置き場
└── X/
    ├── posts/x_posts_tomorrow.md   ← 人間が読む投稿一覧（時間順）
    ├── buffer/x_posts_tomorrow.csv ← Buffer手動入力用（10列）
    ├── buffer/x_posts_tomorrow.json← 同じ内容のJSON
    ├── canva-prompts/              ← 絵画投稿のCanva用プロンプト
    └── images/                     ← 生成した画像の保存先
```

> `_generate.py` は CSV / JSON / 投稿一覧.md を同じ内容から書き出すための補助スクリプトです。
> 本文を直したいときは `_generate.py` の `POSTS` を編集して `python3 SNS/_generate.py` を実行すると、3ファイルがまとめて更新されます。

## 投稿のやり方（Buffer無料版 / X公式予約）

1. `X/posts/x_posts_tomorrow.md` を開き、時間順に投稿本文をコピー。
2. Buffer または X の予約投稿に貼り付け、`recommended_time` の時刻で予約。
3. 画像が必要な投稿（絵画2本）は、`X/images/` の該当ファイルを添付。
4. リプライ文がある投稿（app_cta）は、投稿を予約したうえで**本投稿へのリプライ**としてリンクを送る。

## 運用ルール（今は守りすぎないくらいでOK）

- **Buffer無料版は X の同時予約が10件まで**。本数を増やしすぎない。
- 最初は **1日5〜7投稿** で様子を見る（今回は10本用意しているので、反応を見て間引いてもよい）。
- **リンク投稿は少なめに**。本文に毎回リンクを入れない。
- **リンクは必要に応じてリプライに入れる**（本文の到達を下げないため）。
- **app_cta 投稿は1日1本まで**。
- **絵画投稿（emotional_painting）は共感・リポスト狙い**。本文は語りすぎない。
- **画像付き投稿は1日2本まで**。
- **ハッシュタグは基本なし**。使う場合も最大1つ。
- **自動いいね・自動フォロー・自動DMはしない**（手動運用のみ）。
- Buffer への自動投稿はしない。**手動予約用の素材作成まで**が役割。
