# X運用方針（10日間）― @oyamimamori_jp / 親みまもり研究所

対象期間: 2026-06-24 〜 2026-07-03（1日5本 × 10日 = 50本）
目的: 宣伝アカウントに見せず、「離れて暮らす母・父をさりげなく見守る」共感メディアとして自然に育て、最終的に Roll Call アプリ（LP: https://www.oyamimamori.jp/app/ ）への導線につなげる。

## 1. 10日間の運用方針

- フォロワーが少ない初期段階。**まずは“共感の蓄積”を最優先**し、宣伝は最小限に。
- 1日5本（08:10 / 12:15 / 16:45 / 20:15 / 22:30）を固定リズムに。タイムラインに自然に存在する状態をつくる。
- 1行目で必ず立ち止まらせる。1投稿は短く。同じ言い回しは繰り返さない。
- リンクは原則入れない。app導線は1日1本（22:30枠）まで。

## 2. どの投稿タイプを伸ばすか

現状、**短い共感テキストが最も安定**（72view / 56view 帯）。そこで：

- **主力 = morning_empathy・checklist_or_question**（朝の共感、問いかけ）。保存・共感リプライ・リポストを狙う。
- **practical_tip** は「役立つから follow する」理由をつくる。保存されやすい。
- **emotional_painting** は世界観づくりの担当（後述）。
- 伸びた投稿の「型」（語り出し・テーマ）を、翌週の通常投稿に流用して強化する。

## 3. 画像投稿（emotional_painting）の役割

- 役割は**世界観とブランド想起**。短文ほど数字は伸びない前提で、無理に増やさない。
- **1日1本まで**（10日で10枚）。プロフィールを見たときに「やさしい専門メディア」に見える効果を狙う。
- 文字・ロゴは入れない絵画調。広告に見せない。

## 4. app誘導の頻度

- **app導線は1日1本（22:30）まで。** そのうち**本文にリンクを入れるのは10日間で4本だけ**（Day2・Day5・Day8・Day10）。
- 残り6日は、22:30をソフト誘導にして**リンクはリプライのみ**。
- CTA文言は毎回変える。アプリ名（Roll Call）は出しすぎない。「離れて暮らす母・父を無理なく見守る方法」として紹介する。

## 5. Buffer無料版での予約方法

1. `SNS/X/posts/x_posts_10days.md` を日付・時間順に開く。
2. Buffer に各投稿本文を貼り、`recommended_time` で予約（**無料版は予約枠が10件まで**）。
3. 絵画投稿は `SNS/X/images/dayNN_emotional_painting.png` を添付。
4. リプライ文がある投稿は、投稿予約後に**本投稿へのリプライ**としてリンクを送る（Bufferのリプライ機能がなければ手動）。
5. 予約枠が空いたら次の日を追加していく。

## 7. 反応を見るべき指標

- **保存（ブックマーク）数**：共感メディアでは最重要。実用・チェック投稿で伸びるか。
- **リポスト / 引用**：拡散の核。emotional系・問いかけで起きやすい。
- **プロフィールクリック → フォロー転換**：単発バズより重要。

- 平均 view と「いいね率」。72/56view帯を基準に、超えた型を伸ばす。
