# 収益化記事カード設計（記事一覧用）— 親みまもり研究所

記事一覧・カテゴリで「収益化記事」を見せるためのカード。**商品カードではない**（商品は記事本文の中だけ）。

## 通常の記事カードとの違い
- 通常カード＋**「※記事内に広告・PRを含みます」ラベル**を追加するだけ。
- 見た目は他の記事カードと**同じ体裁**（宣伝色を出さない＝一覧の信頼感を保つ）。

## 要素
```
[オリジナルアイキャッチ]
カテゴリchip
記事タイトル
短い説明
#タグ ・ 投稿日
※記事内に広告・PRを含みます   ← 収益化記事のみ小さく表示
```

## ルール
- 商品名・価格・「Amazonで見る」等のボタンは**カードに出さない**（記事本文でのみ）。
- 収益化記事も非収益化記事も**同じグリッドに混在**（露骨に分けない）。
- ラベルは控えめ（小さめ・グレー）。誤認防止が目的で、煽らない。

## 実装メモ（人間確認後）
- `src/content/config.ts` に任意 `hasAffiliate: z.boolean().default(false)` を追加。
- `ArticleCard.astro` で `hasAffiliate` のとき PR ラベルを表示。
