# カテゴリページ設計 — 親みまもり研究所

目的：カテゴリページを「記事カード一覧＋収益化記事への導線」にする。**商品画像は置かない。**

## レイアウト（上→下）
1. カテゴリ見出し（CSSアイコン＋名前）＋**カテゴリ説明文**（1〜2文）
2. **記事カードのグリッド**（`article_card_design.md` 準拠、収益化記事と非収益化記事を混在）
3. （任意）他カテゴリへのリンク
4. **下部に表示広告1枠のみ**（記事下_レスポンシブ相当）。商品画像リンクの直置きは**しない**

## 6カテゴリ（追加分）と説明文例
| slug(案) | 名称 | 説明文 |
|---|---|---|
| family-record | 家族の記録 | 離れて暮らす家族の思い出や大切なことを、無理なく残していくためのヒント。 |
| family-tree | 家系図・ルーツ | 家族のルーツをたどる、やさしい始め方。話すきっかけとして。 |
| distant-parent | 離れて暮らす親 | 実家の親が気になる人へ。ちょうどいい距離感の見守り。 |
| jikka-bousai | 実家の備え | 実家の防災・連絡手段。もしものときに家族がつながるために。 |
| memories | 思い出の残し方 | 写真・声・言葉。今のうちに残しておけること。 |
| mimamori | 見守りと安心確認 | 見守りは監視ではなく、安心の確認。続けられる方法を。 |

> 実装は既存の `src/pages/categories/[category].astro` を拡張（人間確認後）。既存5カテゴリ＋新6は運用判断で統廃合。

## 収益化の扱い
- 収益化記事カードには「※記事内に広告・PRを含みます」ラベルを表示。
- **商品は売らない**。カテゴリページは「収益化記事を見せる」場所。
- 優先表示：防災/見守り/スマホ/実家の備え 系を上位に出せる並びに。

## 禁止
- 記事一覧/カテゴリに商品画像リンクを大量表示。
- /appページ・Early Adopter LPと同じ広告を混ぜる。
- FV直下の大きな広告。
